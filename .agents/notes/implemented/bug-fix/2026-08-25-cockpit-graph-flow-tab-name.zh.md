# Agent Note: 实验台 只命名仪表台；驾驶舱面板为 图谱·过程流

Status: implemented

[English](2026-08-25-cockpit-graph-flow-tab-name.md) | 中文

## 问题

v3 仪表台（`packages/client/ui-ph-dash`，conversation.view id 为 `dash`，order -20）取名 实验台 并成为会话的默认组合视图，但更早的图谱加时间线合并视图（`packages/client/ui-ph-livegraph`，id 为 `lab`，order -10）仍保留自己的 实验台 标签。标签条与仪表台读取同一份 conversation.view 账本，因此两个条目都会渲染，中文下标签条出现了两个都写着 实验台 的标签——操作者分不清仪表台与它所停靠的面板。英文不受影响（Cockpit 对 Lab）。

## 决定

`lab` 视图的标签改为 图谱·过程流 / Graph · Flow，命名这个面板本身——同一个 `RunFeedProvider` 下的 执行图谱 图和 过程流 时间线。实验台 现在只命名 `dash` 仪表台。`lab` 条目仍然注册，以便仪表台把它作为默认驾驶舱面板停靠；只改了它的 `view.lab` 标签。`ui-ph-livegraph` 与 `ui-ph-dash` 中把该面板称作 实验台 或称作会话默认视图的注释已更正，因为默认视图现在是 order -20 的 `dash`。

## 考虑过的替代方案

- **把 `lab` 从标签条移除但仍可停靠。** 标签条与仪表台读取同一份 conversation.view 账本，因此把 `lab` 从标签条去掉也会把它从仪表台去掉。留一个、藏另一个需要新增一个每条目的"从标签条隐藏"标志——反而给这类冲突增加了面。
- **只改中文标签。** 会让中英文以不同原则命名同一个视图，之后的英文读者又要重新纠结为什么 `lab` 这里叫 "Lab"、那里叫 graph·flow。
- **改仪表台的名字。** 实验台 是仪表台既有的名字及其默认视图角色；改宿主而不改所停靠的面板只是把困惑挪走，而非解决。

## 后果

停靠的驾驶舱面板标题读作 图谱·过程流，与其内容相符，并与独立的 执行图谱（order 19）和 过程流（order 18）标签相区分。id、order 和接线都没变，因此仪表台的默认布局仍把 `lab` 作为驾驶舱面板停靠，也不迁移任何已存布局。本次改动是若干本地化字符串加上更正的注释。
